Review Teknis: Mengapa Tidak Memakai Framework Agen Eksternal?

Banyak solusi text-to-SQL mengandalkan rantai agen generik. Pada sistem data internal perusahaan, pola tersebut kerap memicu overhead latensi tinggi dan risiko eksekusi yang tidak terkendali.

Kelemahan Framework Agen Standar

Implementasi agen generik memperlakukan LLM sebagai eksekutor bebas yang berinteraksi langsung dengan database:

  • Raw write vulnerability: Eksekusi string SQL dilakukan tanpa isolasi level koneksi, rentan terhadap prompt injection yang merusak tabel.
  • Ledakan kuota token: Dump seluruh skema dari puluhan tabel menghabiskan 8.000 hingga 15.000 token per kueri.
  • Latensi agentic loop: Mekanisme pemikiran berantai menimbulkan penundaan 12 hingga 30 detik untuk pertanyaan analitik sederhana.
  • Jejak audit parsial: Riwayat pertanyaan dan pengguna tidak terikat pada tabel kepatuhan append-only.

Pendekatan Desain InsightKit

InsightKit membatasi ruang kendali model dan mengamankan titik temu kueri secara terukur:

  • Isolasi koneksi read-only ganda: Ditegakkan langsung pada sesi driver database (default_transaction_read_only) serta validasi sintaks sebelum eksekusi.
  • Penyaringan skema cerdas: Ekstraksi skema lokal menyaring tabel relevan dan relasi foreign key terkait (budget di bawah 3.000 token).
  • Koreksi mandiri terikat: Kegagalan sintaks dikoreksi maksimal 3 kali sebelum memberikan laporan transparan kepada pengguna.
  • Audit log append-only: Setiap instruksi, latensi, token, dan role dicatat ke SQLite internal tanpa metode update atau delete.

1. Proteksi Read-Only Mutlak

Driver database dipaksa read-only: PostgreSQL menggunakan default_transaction_read_only, SQLite menggunakan URI mode=ro, dan MySQL menggunakan session read-only.

2. Sanitasi PII Otomatis

Pola regex terintegrasi menyaring alamat email, nomor telepon, NIK 16 digit, dan nomor kartu sebelum teks dikirim ke model dan sebelum dicatat ke log audit.

3. Kontrol Akses Peran (RBAC)

Tiga tingkat peran: Viewer (tanya dan lihat skema), Analyst (akses metrik performa), dan Admin (akses log audit dan pembaruan skema).

Konektivitas Mesin Data

Dukungan Database Perusahaan

Satu antarmuka terpadu untuk berbagai mesin database relasional dan repositori dokumen.

PostgreSQL SQLAlchemy Async

Dukungan penuh dengan psycopg3 async. Teruji pada dataset transaksi besar dengan session read-only.

MySQL / MariaDB asyncmy Driver

Koneksi non-blocking murni dengan penegakan transaksi read-only di awal session koneksi.

SQLite aiosqlite Engine

Sangat cocok untuk pengujian lokal, server edge, serta penyimpanan metadata audit internal.

MongoDB Motor AsyncIO

Menghasilkan aggregation pipeline terstruktur. Tahap penulisan seperti $out dan $merge diblokir ketat.

OpenSearch / Elastic SQL REST Plugin

Kueri analitik berbasis SQL di atas klaster pencarian tanpa membebani memori agen.

Trino / Presto REST Statement API

Integrasi kueri terdistribusi untuk data lakehouse dan federasi multi-katalog skala besar.
